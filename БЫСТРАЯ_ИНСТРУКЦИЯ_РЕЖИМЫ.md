# 🎮 Быстрая инструкция - GameObject'ы режимов

## Что нужно сделать в Unity:

### 1. Создать два GameObject'а на сцене 2_Home:
- **NormalModeIcon** (для Normal режима)
- **ArcadeModeIcon** (для Arcade режима)

### 2. Настроить GameObject'ы:
Добавьте в каждый:
- Image с иконкой
- Text с названием режима
- Любые другие элементы

### 3. Выключить оба GameObject'а:
- Снимите галочку на NormalModeIcon
- Снимите галочку на ArcadeModeIcon

### 4. Привязать к PanelRanking:
В Inspector компонента PanelRanking:
- **Normal Mode Object** → перетащите NormalModeIcon
- **Arcade Mode Object** → перетащите ArcadeModeIcon

---

## Как работает:

- При открытии рейтинга → включается GameObject текущего режима
- При нажатии кнопки Normal → включается NormalModeIcon, выключается ArcadeModeIcon
- При нажатии кнопки Arcade → включается ArcadeModeIcon, выключается NormalModeIcon

---

**Готово!** Теперь пользователи будут видеть, в каком режиме они находятся! 🎉
