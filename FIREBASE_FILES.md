# Firebase Large Files

Из-за ограничений GitHub (максимум 100 MB на файл), следующие файлы Firebase не включены в репозиторий:

## Отсутствующие файлы:

- `Assets/Firebase/Plugins/x86_64/FirebaseCppApp-13_9_0.bundle` (189.92 MB)
- `Assets/Firebase/Plugins/x86_64/FirebaseCppApp-13_9_0.so` (122.39 MB)
- `Assets/Firebase/Plugins/x86_64/FirebaseCppAuth.bundle`
- `Assets/Firebase/Plugins/x86_64/FirebaseCppAuth.so`
- `Assets/Firebase/Plugins/x86_64/FirebaseCppDatabase.bundle`
- `Assets/Firebase/Plugins/x86_64/FirebaseCppDatabase.so`
- `Assets/Firebase/Plugins/x86_64/FirebaseCppFunctions.bundle`
- `Assets/Firebase/Plugins/x86_64/FirebaseCppFunctions.so`

## Как восстановить:

1. Скачайте Firebase SDK для Unity с официального сайта: https://firebase.google.com/download/unity
2. Импортируйте нужные пакеты Firebase в Unity
3. Файлы автоматически появятся в папке `Assets/Firebase/Plugins/x86_64/`

Или свяжитесь с владельцем проекта для получения этих файлов.
